# kuradesk_chat example

Demonstrates both integration styles:

- `KuradeskChatLauncher` — floating chat button overlaid on your app.
- `KuradeskChatView` — the chat panel rendered as a full screen.

## Run

Set `kuradeskApiBaseUrl` and `kuradeskWidgetKey` in `lib/main.dart` to the values
from **KuraDesk → Settings → Chat plugins**, then:

```sh
flutter run
```
